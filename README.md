# rvdmijnsbrugge.github.io

Emergence: a CSS framework based on behavioral science. A static storefront prototype with three pages:

- `index.html` – home
- `collection.html` – collection listing
- `product.html` – product detail

## Source

The pages are authored on CodePen: https://codepen.io/editor/rvdmijnsbrugge/pen/019cc2b9-c4ef-72ca-ab1a-932150769625
